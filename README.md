# メロのピアノれんしゅう

子ども向けピアノ練習アプリ(Duolingo風)。`index.html` をブラウザで開くだけで動きます(インストール不要)。

## 生徒の練習コーナー
1. **がくふを よもう** — 先生が選んだ音符(ト音/ヘ音)をドレミで答えるクイズ。ハート3つ、正解でコイン。
2. **リズムうち** — 先生が選んだリズムを、お手本を聞いてからドラムをタップ。タイミングを判定して★1〜3。
3. **きょくの れんしゅう** — 先生の**おてほん演奏**(録音・動画)を ゆっくり再生・区間くりかえしで聞ける。先生が取り込んだ楽譜画像にピン・ペンで注意を書き込み。チェックリスト、タイマー、「通して弾けた」カウンター、ふりかえり。15分ごとに「目をやすめよう」休憩。

## やる気のしくみ
- コイン・連続日数(ストリーク)・週の目標と宝箱
- マスコット「メロ」: 練習すると喜び、1日休むと不安顔、3日以上休むと真っ赤になって怒る
- ショップでコインを使ってメロの帽子・めがね・背景を買える

## 先生用ページ(暗証番号つき)
- 音符・リズム(オリジナル作成可)・テンポ・曲・チェックリスト・週の目標・ひとことを設定
- 2週間の練習記録と生徒の自己評価を確認
- 「課題ファイルを保存/読みこむ」で先生の端末から生徒の端末へ課題を渡せます

## データの保存と受け渡し
- claude.ai で共有したページでは、先生が変えた課題が自動で生徒に届き(「みんな(共通)」の課題と、生徒ごとの専用課題を使い分けられます)、生徒の練習記録が先生の「記録」タブに届きます(先生=編集者、生徒=コントリビューター以上で共有)。
- `index.html` を直接開いた場合は端末のブラウザ(localStorage)に保存され、課題はファイルで受け渡します。

## 対応端末
iPhone・Android スマホ、iPad・Android タブレット、パソコンのブラウザ。タブレットでは楽譜と練習パネルが横並びになり、練習中は画面が消えにくくなります。iPhone/iPad はマナーモードでも音が出ます。
