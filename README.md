# 家族の予定表

家族の予定を共有する Web アプリです。スマホのブラウザで使えます。

- **家族の予定**: 家族ごとに「今日」と「これから7日間」の予定を一覧で表示します
- **カレンダー**: 月ごとのカレンダーに、だれの何の予定かを表示します。日付をタップすると、家族が横に並び予定が時間ごとに縦に並ぶ「バーチカル表示」になります
- **送迎**: 予定ごとに「送り」「迎え」の担当を選べます。担当の人の「今日」の一覧と、バーチカル表示の担当の列にも表示されます
- **声で入力**: マイクのボタンを押して「明日の4時から5時、ゆいの水泳、送りは母、迎えは父」のように話すと、日付・時刻・だれ・送迎・内容を自動で振り分けて入れます（Chrome や Safari で使えます）
- **家族・設定**: 家族は何人でも追加でき、それぞれに色を付けられます
- **安全性**: Google ログインが必要です。管理者が許可したメールアドレスの人だけが、予定を見たり書き込んだりできます

設定する前に、`?demo` を付けて開くとデモモードで試せます（データはその端末の中だけに保存されます）。

## はじめての設定手順

### 1. Firebase プロジェクトを作る

1. https://console.firebase.google.com を開き、Google アカウントでログインします。
2. 「プロジェクトを作成」を押し、名前（例：`family-schedule`）を入れて進みます。
3. 「Google アナリティクス」はオフで大丈夫です。

### 2. Google ログインを有効にする

1. 左メニューの「構築」→「Authentication」→「始める」を押します。
2. 「Sign-in method」タブで「Google」を選び、「有効にする」をオンにして、サポートメールを選んで保存します。
3. 「設定」タブ →「承認済みドメイン」→「ドメインを追加」で、次を追加します。
   ```
   miiya-stack.github.io
   ```

### 3. データベース（Firestore）を作る

1. 左メニューの「構築」→「Firestore Database」→「データベースを作成」を押します。
2. ロケーションは `asia-northeast1（東京）` を選びます。
3. 「**本番環境モード**」を選んで作成します。

### 4. セキュリティルールを設定する（とても大事）

1. Firestore Database の「ルール」タブを開きます。
2. このリポジトリの [`firestore.rules`](firestore.rules) の中身を**全部コピーして貼り付け**ます。
3. `YOUR_EMAIL@gmail.com` の部分を、**あなた（管理者）の Gmail アドレス**に書き換えます。
4. 「公開」を押します。

### 5. アプリに Firebase をつなぐ

1. 左上の歯車 →「プロジェクトの設定」を開きます。
2. 下の「マイアプリ」で `</>`（ウェブ）を押し、名前を入れて「アプリを登録」します（Hosting はチェック不要）。
3. 表示された `firebaseConfig = { ... }` の中身を、[`js/firebase-config.js`](js/firebase-config.js) の同じ項目に書き写します。
   - この値は公開されても問題ありません。データは手順4のルールで守られます。

### 6. GitHub Pages で公開する

1. GitHub でこのリポジトリを開き、「Settings」→「Pages」を開きます。
2. 「Branch」で `main` と `/ (root)` を選んで「Save」を押します。
3. 1〜2分後、次の URL で開けるようになります。
   ```
   https://miiya-stack.github.io/my-app/
   ```

### 7. 家族を招待する

1. 管理者のアカウントでアプリにログインします。
2. 「家族・設定」→「アクセスできる人」に、家族の Gmail アドレスを追加します。
3. 家族に URL を送ります。家族は自分の Google アカウントでログインすると使えます。
4. 「家族メンバー」に、予定を管理したい家族（パパ、ママ、子どもなど）を追加します。

> スマホでは、ブラウザのメニューから「ホーム画面に追加」すると、アプリのように開けます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/app.js` | 画面の動き |
| `js/store-firebase.js` | Firebase とのやりとり |
| `js/store-local.js` | デモモード用（端末内に保存） |
| `js/firebase-config.js` | Firebase の設定値 |
| `firestore.rules` | データを守るセキュリティルール |
