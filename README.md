# メロのピアノれんしゅう

子ども向けピアノ練習アプリ(Duolingo風)。`index.html` をブラウザで開くだけで動きます(インストール不要)。

## 生徒の練習コーナー
1. **がくふを よもう** — 先生が選んだ音符(ト音/ヘ音)をドレミで答えるクイズ。ハート3つ、正解でコイン。
2. **リズムうち** — 先生が選んだリズムを、お手本を聞いてからドラムをタップ。タイミングを判定して★1〜3。
3. **きょくの れんしゅう** — 先生が取り込んだ楽譜画像にピン・ペンで注意を書き込み。チェックリスト、タイマー、「通して弾けた」カウンター、ふりかえり。15分ごとに「目をやすめよう」休憩。

## やる気のしくみ
- コイン・連続日数(ストリーク)・週の目標と宝箱
- マスコット「メロ」: 練習すると喜び、1日休むと不安顔、3日以上休むと真っ赤になって怒る
- ショップでコインを使ってメロの帽子・めがね・背景を買える

## 先生用ページ(暗証番号つき)
- 音符・リズム(オリジナル作成可)・テンポ・曲・チェックリスト・週の目標・ひとことを設定
- 2週間の練習記録と生徒の自己評価を確認
- 「課題ファイルを保存/読みこむ」で先生の端末から生徒の端末へ課題を渡せます

データは端末のブラウザ(localStorage)に保存されます。
