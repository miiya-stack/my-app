# dolce cantabile — website redesign

Redesigned static homepage for 「ぴあの、りとみっく dolce cantabile」 (https://dolcan.online/).

- `index.html` — one-page site (Message / Features / Lessons & prices / Schools / Instructors / Flow / FAQ / News / Contact / Info)
- `css/style.css` — styles (responsive, ivory × navy × gold)
- `js/main.js` — header, mobile menu, scroll-reveal
- `assets/img/` — photos taken from the current site, resized

Open `index.html` in a browser to preview. No build step.
