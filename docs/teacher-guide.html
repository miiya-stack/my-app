メロのピアノ 先生向けガイド

先生が課題を出し、子どもが毎日の練習を楽しく続けるためのアプリです。このページの手順で、先生ご自身専用のアプリを作って使えます。

できること

4つの練習と、続けたくなるしかけ

がくふを よもう先生が選んだ音符をドレミで答える。ト音記号 → ヘ音記号 → 大譜表とステップアップ。
リズムうち「4分と2分」「8分と4分」「8分・4分・2分」「休符」の各5問と、先生オリジナル。
ゆびばんごう手の絵で指番号を覚えるクイズと、光る指を見て机の上で動かす練習。
きょくの れんしゅう楽譜の写真に注意を書きこみ、先生のおてほん演奏をゆっくり・区間くり返しで聞ける。

コイン・連続日数・週の宝箱、練習しないと赤くなって怒るマスコット「メロ」で、子どものやる気を支えます。先生が変えた課題は生徒の端末に自動で届き、生徒の練習記録は先生の画面に届きます。生徒ごとに違う課題も出せます。

はじめに 1回だけ

自分専用のアプリを作る

必要なもの: claude.ai のアカウント(Claude Code が使えるもの)。所要時間は5分ほどです。

  1. アプリのファイルを保存する

  2. Claude Code を開いて、ファイルと文を送る

    claude.ai/code で新しいセッションを開き、保存したファイルを添付して、下の文を貼りつけて送信します。

  3. できたリンクを開いて、課題を作る

    Claude から届いたリンクを開き、下の「せんせい」から、音符・リズム・指番号・曲・先生のひとことを設定します。楽譜の写真やおてほんの録音もここで登録します。

このアプリは、作った先生だけのものになります。ほかの先生の生徒や記録とはまざりません。直したいところや足したい機能は、同じように Claude に頼めば変えられます。
生徒に渡す

生徒・保護者を招待する

  1. アプリのページ右上の「共有」から、生徒(保護者)のメールアドレスで招待します。権限は「コントリビューター」(選べない場合は閲覧者)にします。「編集者」にはしないでください(課題を変えられてしまいます)。

  2. 「リンクをコピー」でリンクをコピーし、LINE やメールで送ります。

  3. 生徒は、招待されたアカウントで claude.ai にログインしてから開きます。ログインしていないと課題が届かず、「せんせい」ボタンも出ません。

生徒の保存のしかた(ホーム画面に置く)

端末やり方
Android(Chrome)右上の「︙」→「ホーム画面に追加」
iPhone・iPad(Safari)共有ボタン(□に↑)→「ホーム画面に追加」
パソコンブックマークに保存(Edge なら「︙」→「アプリ」→「このサイトをアプリとしてインストール」)
最初は1家族だけ招待して試すと安心です。生徒が1回練習したあと、先生の「せんせい」→「記録」にその子の名前が出れば、記録も届いています。
よくある質問

気をつけること

生徒にも claude.ai のアカウントが必要ですか?

はい。課題を受け取り、記録を先生に届けるにはログインが必要です。ログインしないで開いた場合は、その端末だけで練習する形になります。

生徒ごとに違う課題を出せますか?

できます。生徒が一度アプリを開いて練習すると、「せんせい」の上に名前が出ます。名前を選んで「専用の課題を つくる」を押してください。

記録が先生に届きません。

アカウントの種類によっては、外部の人を「閲覧者」でしか招待できないことがあります。その場合でも課題は届きますが、記録は生徒の端末にだけ残ります。

マナーモードのときは音が出ませんか?

iPhone・iPad は消音スイッチで音が止まります。Android やパソコンは、アプリ右上のスピーカーのボタンで音を消せます。

Claude Code を使わずに試すだけはできますか?

できます。保存した melo-piano.html をパソコンやタブレットのブラウザで直接開くと、その端末だけで動きます(自動の受け渡しはなし)。課題は「せんせい」→「課題・設定」のファイル保存・読みこみで生徒の端末に渡せます。
